# 小竹Flash浏览器 v1.6.1

macOS 版。下载 DMG 拖进「应用程序」即可；ZIP 是同一份 app，只是方便用微信、QQ 传。

## 这一版新增

- 焦点模式：一个窗口里多个账号同时实时运行，主画面加实时缩略图条带，也可以按左右或四宫格分区排布。切换只做 GPU 变换，页面不重载、不掉帧。⌘⇧F 进出，⌘⇧D 在条带与分区之间切。
- 命令面板：⌘K 唤出，搜账号、标签页、书签、历史、设置页和常用动作，回车直接执行。
- 状态条：界面帧率、各进程 CPU、每个账号的连接状态，常驻一行，不遮挡游戏。⌘⇧B 开关。
- 崩溃恢复：重开后恢复上次的窗口、档案、标签页和焦点模式布局，带崩溃循环保护。
- 页面净化与整数倍缩放：按站点隐藏广告位和杂项，可把游戏居中；缩放对齐到设备像素的整数倍，Flash 边缘不再发虚。
- 自动登录与快速进入：按档案单独开关，复用已有的密码管线；记住每个档案上次玩的地址。
- 统一浮层样式：菜单、面板、提示的圆角、投影、层级和材质收到同一套 token 上。
- 首启引导与空状态：第一次打开有三步引导；空页面给出可以直接点的下一步。
- 新标签页目标可设置：新标签页打开哪里由你决定，不再写死。

## 关于这个发布版

发布出来的这一份不包含竞技辅助，也不包含测距叠层 —— 代码、入口、菜单项都没有，不是藏起来了。

## 第一次打开

这个 app 没有苹果开发者签名，直接双击会被系统拦下，提示「已损坏」或「无法验证开发者」。那是 Gatekeeper 的默认拦截，不是文件坏了。

正确的打开方式：右键点图标，选「打开」，再点一次「打开」。

如果是 macOS 15 及以上，可能还需要去 系统设置 → 隐私与安全性，在下面点「仍要打开」。

## 隐私

DMG 和 ZIP 里只有 app 本身。档案、密码、历史、cookie 全部存在

    ~/Library/Application Support/小竹Flash浏览器/

那是 app 包外面的目录，不会被打包。装上后是一个全新的空浏览器。

## 校验

每个包都附了一个 .sha256。核对：

    shasum -a 256 -c XiaozhuFlashBrowser-macOS-v1.6.1.dmg.sha256
